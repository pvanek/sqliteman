# Keyboard shortcuts

```{index} shortcuts, keyboard
```

On macOS, {kbd}`Ctrl` below is {kbd}`Cmd`.

## Anywhere

| Keys | Does |
|---|---|
| {kbd}`Ctrl+O` | Open a database or a script |
| {kbd}`Ctrl+N` | New SQL editor, on the database selected in the browser |
| {kbd}`Ctrl+S` / {kbd}`Ctrl+Shift+S` | Save the script, or the grid's changes when the grid has focus / Save the script as |
| {kbd}`Ctrl+W` | Close the tab |
| {kbd}`Ctrl+B` | Go to the database browser |
| {kbd}`Ctrl+Shift+B` | Go to the file browser |
| {kbd}`F6` | Go to the editor |
| {kbd}`F1` | The manual, at the page for what is shown |
| {kbd}`Ctrl+Q` | Quit |

## The SQL editor

| Keys | Does |
|---|---|
| {kbd}`Ctrl+Enter` | Run the statement under the cursor, or the selection |
| {kbd}`Ctrl+Shift+Enter` | Run the whole script |
| {kbd}`Ctrl+E` | Explain the query plan |
| {kbd}`Ctrl+.` | Stop what is running |
| {kbd}`Ctrl+Space` | Complete |
| {kbd}`Tab` | Expand the template before the cursor |
| {kbd}`Ctrl+/` | Comment the lines out, or in |
| {kbd}`Ctrl+F` / {kbd}`Ctrl+R` | Find / Find and replace |
| {kbd}`F3` / {kbd}`Shift+F3` | Next / previous match |
| {kbd}`Ctrl+H` / {kbd}`Ctrl+Shift+H` | Find the selection or the word at the cursor, forwards / backwards |

## Results

| Keys | Does |
|---|---|
| {kbd}`Ctrl+C` | Copy the selected cells |
| {kbd}`Shift+Enter` | View or edit the value |
| {kbd}`Ctrl+Insert` | Add a row |
| {kbd}`Del` | Delete the selected rows, or take that back |
| {kbd}`Ctrl+Shift+N` | Set the selected cells to `NULL` |
| {kbd}`F5`, {kbd}`Ctrl+R` | Run the query again |

## The database browser

| Keys | Does |
|---|---|
| {kbd}`Enter` | Open the selected table, view or object |
| {kbd}`F5`, {kbd}`Ctrl+R` | Read the schema again |
